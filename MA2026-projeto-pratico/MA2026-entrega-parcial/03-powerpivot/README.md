# Etapa 3 — Power Pivot e DAX | TechShop Brasil

O arquivo `TechShop_03_PowerPivot.xlsx` contém Modelo de Dados nativo com sete tabelas (incluindo a tabela isolada de rejeitados), seis relacionamentos, 25 medidas DAX e cinco Tabelas Dinâmicas.

- Modelo e chaves: `docs/modelo_relacional.md`.
- Medidas exportadas: `dax/medidas_preliminares.dax`.
- Consultas M: `scripts_m/*.pq`.
- Evidências: `evidencias/*.png` (diagrama, medidas, conferência e Tabelas Dinâmicas).
- Análises: `PT_Lojista_Mes`, `PT_Metas`, `PT_Categoria`, `Conf_DAX_VALORCUBO`, além de `Planilha1`/`Planilha2`.

Fonte: tabela tratada da Etapa 2. Para recalcular em outro computador, ajuste os parâmetros e execute `Atualizar Tudo` primeiro na Etapa 2, depois na Etapa 3. Veja `../04-documentacao/GUIA_ATIVACAO_NO_EXCEL.md`.
